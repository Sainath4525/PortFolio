Dhara – Indian Folk Art Marketplace

Full-Stack Architecture | React.js · Node.js · Express.js · MongoDB · JWT · bcrypt

Dhara is an end-to-end full-stack digital marketplace crafted to bridge the gap between traditional Indian folk artists and art connoisseurs worldwide. Many indigenous artisans lack direct digital commerce channels; Dhara provides them with a dedicated platform to showcase heritage artwork styles such as Madhubani, Warli, Gond, and Pattachitra.

1. Full-Stack Discovery & Real-Time Search

The client-side interface is developed with React.js and styled using Material UI for a polished, responsive presentation. It features dynamic artist profile pages, structured categories, and instant client-side filtering that enables users to browse by artwork style, medium, pricing tiers, and regional origins.

2. Security & Role-Based Access Control (RBAC)

To guarantee secure access, the backend utilizes JSON Web Tokens (JWT) for stateless session verification alongside bcrypt cryptographic hashing for user passwords. The platform strictly enforces Role-Based Access Control:

  • Artists: Dedicated administrative views to create, update, and manage artwork listings, upload high-resolution photos, configure inventory, and view buyer interest.
  • Buyers: Seamless exploration of art galleries, secure user accounts, cart management, and direct inquiries with artists.

3. Scalable Backend & Data Modeling

The service layer is built on Node.js and Express.js, maintaining clear separation between controllers, routing middleware, and data models. MongoDB was chosen for its schema flexibility, facilitating rich document structures for varied art dimensions, regional techniques, provenance descriptions, and multimedia assets.
