SmartWallet – Wallet Management System

2025 · Transactional Backend Systems | Node.js · Express.js · MySQL · Stored Procedures · Triggers · JWT · bcrypt

SmartWallet is a high-reliability digital financial wallet engine architected to handle peer-to-peer (P2P) transfers and merchant settlement workflows. The primary focus of the system is absolute data integrity, ACID compliance, zero race condition balance corruption, and resilient failure recovery.

1. Atomic Execution via MySQL Stored Procedures

Financial transfers between users require updating two separate balances (debiting sender, crediting receiver) while logging a ledger entry. To prevent network partitions or server crashes from causing partial balance updates:

  • The transaction logic is encapsulated inside dedicated MySQL Stored Procedures wrapped with START TRANSACTION and explicit error handlers (DECLARE EXIT HANDLER FOR SQLEXCEPTION) to ensure clean rollbacks.
  • Utilizes Transaction-Hash Idempotency: Each payment request accepts a cryptographic idempotency key. If a client retries due to network timeout, duplicate processing is instantly intercepted.

2. Audit Trails, Triggers & Security Controls

To meet enterprise compliance standards:

  • Designed 5+ MySQL Triggers that monitor mutations across balance tables and automatically write immutable records to an encrypted audit trail table before/after each operation.
  • PIN & Authentication: Sensitive transaction confirmations require a secondary PIN hashed via bcrypt, coupled with JWT authentication and strict Role-Based Access Control distinguishing everyday users from high-volume merchants.

3. Automated Background Events & Financial Analytics

The system features background automation configured natively in MySQL:

  • Scheduled Events: Built automated reward-expiry handling using native MySQL scheduled events (CREATE EVENT) that sweep unredeemed bonus credits at scheduled intervals.
  • Hourly Refund Retry Logic: Failed or unsettled third-party merchant transactions are queued and re-evaluated by an hourly worker process.
  • Monthly Analytics & CSV Export: Summarizes volume, transaction velocity, and fee structures with CSV report generation and visual chart breakdowns.
