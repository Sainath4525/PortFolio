# Sainath Kumbar - Developer Portfolio

A fast, terminal-inspired developer portfolio website designed for **Sainath Kumbar**, Software Engineer & CS undergraduate at the University of Visvesvaraya College of Engineering (UVCE), Bengaluru.

Replicated with the exact design, theme, and aesthetic of [hariomkhonde.vercel.app](https://hariomkhonde.vercel.app/).

## 🌟 Key Features

- **Terminal Hacker Aesthetic**: Sleek `#121212` dark theme with monospace highlights and fluid responsive typography.
- **WebNeko Animated Cursor Pet**: Interactive pixel cat following the user cursor (`webneko.net`).
- **Interactive Terminal Cards**: `cat core_technologies.yml` card detailing Sainath's languages, frameworks, and databases.
- **1-Click cURL Resume**: Copy-to-clipboard command `curl -s https://sainath4525.github.io/resume.json | jq` to inspect structured JSON resume directly in terminal.
- **Education Timeline**: Chronological education track highlighting UVCE Bengaluru (CGPA 8.72), Shahu Maharaj PU College (95.33%), and Sangolli Rayanna High School (88.16%).
- **Project Deep-Dives**:
  - **Dhara**: Full-stack Indian folk art digital marketplace (React.js, Node.js, Express.js, MongoDB, JWT, bcrypt).
  - **SmartWallet**: High-concurrency transactional digital wallet supporting atomic P2P transfers via MySQL stored procedures, 5+ triggers, and scheduled events.
- **Certifications & Skills Matrix**: DevTown HTML/CSS, Campus Champ AWS & Technical Skills, Campus Champ Soft Skills, plus Core CS and spoken languages.
- **ASCII Art Blog**: Terminal ASCII cat "Coming Soon" page.
- **Desktop Sidebars**: Floating vertical social links on the left and vertical email on the right.

## 🚀 Running Locally

You can run this project locally using Node.js:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

Or simply open `index.html` directly in any web browser!
